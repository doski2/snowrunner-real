(`snowrunner-telemetry-api`) **y** la telemetría CE. El foco es **solo XML en `initial.pak`**. Ver
**`METODO-PAK.md`**, **`CE-ARCHIVADO.md`**.

## Qué hacer con la carpeta API

La carpeta `snowrunner-telemetry-api/` (si existe en el disco) queda como **borrador de
investigación**. No es parte del flujo activo hasta nueva decisión explícita.
